
# Revisión de código

Revisar los cambios indicados por el Tech Lead.

Buscar:
- Errores funcionales.
- Regresiones.
- Riesgos de seguridad.
- Problemas de permisos.
- Errores en cálculos.
- Problemas de unidades.
- Problemas de rendimiento.
- Problemas de accesibilidad.
- Manejo de errores.
- Código duplicado.

Clasificar los hallazgos por severidad.

Indicar archivos y líneas afectadas.

No corregir automáticamente.

Proponer soluciones y esperar autorización.
