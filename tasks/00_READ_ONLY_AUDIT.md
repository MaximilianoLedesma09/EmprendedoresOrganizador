
# Auditoría inicial de Organizador

## Objetivo

Comprender el proyecto antes de modificarlo.

## Restricciones

No modificar archivos.
No instalar dependencias.
No actualizar paquetes.
No eliminar archivos.
No realizar despliegues.
No ejecutar migraciones.
No escribir datos en Firebase.
No exponer secretos.

## Inspección requerida

1. Estructura general.
2. Tecnologías y dependencias.
3. Entrada principal de la aplicación.
4. Navegación y vistas.
5. Servicios y modelos.
6. Firebase Authentication.
7. Firestore.
8. Firebase Storage.
9. Hosting y posible backend.
10. PWA y service worker.
11. Inventario.
12. Precios.
13. Ventas.
14. Calendario.
15. Recordatorios.
16. Configuraciones.
17. Tests y validaciones.
18. Seguridad y permisos.
19. Problemas de rendimiento.
20. Funcionalidades incompletas.

## Informe

Para cada hallazgo indicar:
- Archivo y ubicación.
- Qué hace.
- Si está implementado y conectado.
- Evidencia.
- Riesgo.
- Posible mejora.

Separar hechos confirmados de hipótesis.

Proponer cinco mejoras pequeñas y ordenarlas por:
- Impacto.
- Dificultad.
- Riesgo.
- Tiempo estimado.

No implementar ninguna mejora.

Esperar aprobación del Tech Lead.
