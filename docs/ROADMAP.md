
# Roadmap de Organizador

Este roadmap es una propuesta. No autoriza implementaciones.

## Fase 0 — Auditoría

- Inspeccionar el proyecto.
- Identificar funcionalidades reales.
- Revisar Firebase y datos.
- Revisar dependencias.
- Detectar errores.
- Documentar arquitectura.

## Fase 1 — Mejoras iniciales

- Corregir errores comprobados.
- Mejorar validaciones.
- Mejorar experiencia de usuario.
- Preservar las funcionalidades existentes.

## Fase 2 — Definición del negocio

- Confirmar modos fabricante y revendedor.
- Confirmar unidades y monedas.
- Diseñar modelo de datos.
- Probar la fórmula de precios.

## Fase 3 — Catálogos

Fabricante:
- Materiales.
- Unidades.
- Costos unitarios.
- Stock.

Revendedor:
- Productos comprados.
- Costos unitarios.
- Stock.

## Fase 4 — Productos terminados

- Fotografías.
- Datos del producto.
- Confirmación de materiales en modo fabricante.
- Cálculo del costo.
- Precio sugerido.

## Fase 5 — IA

- Análisis de fotografías.
- Sugerencias.
- Confirmación humana.
- Backend seguro.
- Manejo de errores y costos.

## Fase 6 — Tiendas virtuales

- Seleccionar plataforma.
- Investigar API oficial.
- Conectar cuenta de prueba.
- Mapear categorías.
- Preparar borradores.
- Publicación con aprobación.

## Fase 7 — Calendario

- Fechas de carga de productos.
- Fechas de publicación.
- Recordatorios.
- Reprogramación.

## Fase 8 — Redes sociales

- Investigación de APIs.
- Preparación de borradores.
- Programación.
- Publicación con aprobación.

No avanzar de fase sin revisión del Tech Lead.
