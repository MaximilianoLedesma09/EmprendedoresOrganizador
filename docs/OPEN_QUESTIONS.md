
# Preguntas abiertas

Estas preguntas no deben resolverse por intuición.

## Moneda y configuración

1. ¿La primera versión utilizará exclusivamente pesos argentinos (ARS)?
2. ¿El usuario podrá modificar el multiplicador 2,30 y los adicionales de $1.000 y $1.500 desde configuraciones?
3. ¿La fórmula será global para la cuenta o se podrá configurar por producto?
4. ¿Cómo se redondeará el precio final?

## Fabricantes

1. ¿Qué unidades de medida deben soportarse inicialmente?
2. ¿Se necesita historial de compras de materiales?
3. ¿Se descontará automáticamente stock al registrar un producto fabricado?
4. ¿Se debe contemplar desperdicio o merma?
5. ¿Se podrán utilizar varios materiales de un mismo tipo con distintos proveedores y precios?

## Revendedores

1. ¿Se necesita registrar proveedores?
2. ¿Se necesita historial de compras?
3. ¿El costo unitario se actualizará automáticamente al registrar nuevas compras?
4. ¿Cómo se manejarán distintas variantes del mismo producto?

## Inteligencia artificial

1. ¿Qué proveedor de IA se utilizará?
2. ¿Se analizará una fotografía o varias?
3. ¿Se permitirán correcciones y aprendizaje a partir de las confirmaciones?
4. ¿Qué información se enviará al proveedor externo?
5. ¿Se necesita un límite de análisis por usuario?

## Tiendas virtuales

1. ¿Cuál será la primera plataforma a integrar?
2. ¿Se crearán borradores o se publicará directamente con confirmación?
3. ¿Cómo se manejarán variantes, stock y categorías?

## Calendario

1. ¿Se necesitan recordatorios?
2. ¿Se podrán reprogramar tareas?
3. ¿Se asociará cada evento a un producto?

## Futuro

1. ¿Se permitirá un modo híbrido?
2. ¿Se implementarán planes gratuitos y pagos?
3. ¿Qué redes sociales serán prioritarias?
