
# Registro de decisiones aprobadas

## D-001 — Proyecto inicial

El código es un esqueleto y no una especificación definitiva.

Debe auditarse antes de modificarlo.

## D-002 — Autoridad técnica

El usuario es Tech Lead.

Cline debe solicitar aprobación explícita antes de modificar cualquier elemento del proyecto.

## D-003 — Modos de negocio

Se contemplan dos modos iniciales:

- Fabricante.
- Revendedor.

No se deben mezclar materiales de fabricación con productos adquiridos para reventa.

## D-004 — Fórmula de precios

Si costo > 7000:

precio = costo * 2.30 + 1500

Si costo <= 7000:

precio = costo * 2.30 + 1000

## D-005 — Confirmación humana

Las sugerencias de IA no son datos definitivos.

El usuario confirma los materiales y cantidades utilizados.

## D-006 — Publicaciones sociales

La automatización de redes sociales queda fuera del alcance inicial.

## D-007 — Preservación

Las funcionalidades existentes deben conservarse salvo autorización expresa para modificarlas.
